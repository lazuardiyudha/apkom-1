Materi Teori

Referensi Relatif & Absolut

  • Relatif (Misal: A1): Posisi sel akan bergeser menyesuaikan baris/kolomnya jika di copy-paste.
  • Absolut (Misal: $A$1): Ditandai dengan lambang dolar (tekan F4 di keyboard). Sangat penting dalam laporan pajak atau gaji, saat Anda mengunci tarif pajak PPN (misal 11% di satu sel teratas) untuk dikalikan dengan seluruh tabel di bawahnya tanpa bergeser.

Styles & Heading

Home → Styles. Terapkan Heading pada judul laporan keuangan, bab, dan subbab. Membantu struktur navigasi dan Daftar Isi.

  1. Blok teks judul
  2. Pilih Home → Heading 1
  3. Klik References → Table of Contents

Tabel Keuangan

Insert → Table. Berguna untuk Neraca dan Laba Rugi sederhana di dokumen Word. Angka umumnya diset rata kanan.

  1. Insert → Table
  2. Layout → Repeat Header Rows
  3. Layout → Formula (=SUM(ABOVE))

Section Break

Layout → Breaks → Next Page. Membuat halaman orientasi Landscape untuk tabel rekapan data yang sangat lebar tanpa mengganggu halaman potrait.

  1. Letakkan kursor di awal halaman
  2. Layout → Breaks → Next Page
  3. Ubah Orientation jadi Landscape

Mail Merge

Mailings → Start Mail Merge. Sangat praktis untuk mengirim tagihan piutang (invoice/surat tagihan) ke ratusan pelanggan berdasarkan data Excel.

  1. Siapkan data pelanggan di Excel
  2. Mailings → Select Recipients
  3. Insert Merge Field

Kanvas Interaktif Word

Simulasi menyusun laporan keuangan. Terapkan Heading, tabel anggaran, dan daftar isi otomatis.
